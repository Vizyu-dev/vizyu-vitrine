# Vizyu — site vitrine

Site statique de présentation de Vizyu destiné aux investisseurs, servi sur www.vizyu.fr (projet Vercel `vizyu-vitrine`).

- `index.html` : contenu de la page
- `styles.css` : styles (charte Vizyu, police Outfit)
- `assets/` : logo et icônes

Contact investisseurs : contact@vizyu.fr (section `#contact`).

Mesure d'audience : Umami Cloud (script dans le `<head>` de chaque page). Pour suivre un clic, ajouter `data-umami-event="nom-de-l-evenement"` sur le lien.
